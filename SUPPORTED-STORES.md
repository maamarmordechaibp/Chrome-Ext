# Supported Stores — Test Checklist

Give this to a representative to verify the **Marketplace Catalog Generator** extension
(v1.0.40+) detects and scans each store.

## How to test each store
1. Open the store's website (links below) in Chrome.
2. **Search for any product** (e.g. "shoes", "tv", "coffee") to reach a results page.
3. Click the extension icon → **Scan Products**.
4. Confirm products (title, image, price) appear, then **Generate PDF**.
5. To test a single item: open one product page and use **Capture this product**.

> Tick the box once a store scans correctly. If a store finds no products, note it —
> some sites change their layout often and may need a selector tune-up.

Legend: ✅ = works · ⬜ = to test · ⚠️ = best-effort (heavy JavaScript site, may need tuning)
